# 2RTK.com 网站群建设方案（静态版）

> 目标：一个「RTK 知识社区 + 公共服务 + 变现」的综合站点。
> 本方案为**全静态架构**——首页用 VitePress，地图用现有 Cesium 页面，caster 独立部署。

## 一、定位与三大入口

| 入口 | 域名/端口 | 作用 | 技术选型 |
|------|----------|------|---------|
| 首页（学习） | `2rtk.com` | RTK 原理、RTCM 原理、搭建教程、带货、捐赠 | VitePress（静态） |
| 地图（展示） | `map.2rtk.com` | 展示基准站覆盖 + 卫星 | 现有 Cesium 页面 |
| Caster 后台（服务） | `caster.2rtk.com` | 用户管理挂载点（数据流 2101） | 已有，不动 |

核心闭环：**看教程 → 用我的 caster 免费测试 → 在地图上看到自己的站点**。

---

## 二、为什么选静态生成器（而非 Halo / 纯手写）

你确认了：**少量教程（5 篇以内）+ 想要简单**。结论：

- ❌ 不用 Halo：教程量不大，CMS 的 Docker + 数据库是多余负担
- ❌ 不纯手写 HTML：5 篇教程手写 HTML 太累，改样式要逐页改
- ✅ **用 VitePress**：写 Markdown 自动生成静态站，改样式一处生效，SEO 好，部署就是个静态目录

### VitePress 优势
- Vue 官方文档同款，中文生态好
- Markdown 写教程，自动生成侧边栏、导航、搜索
- 内置 SEO、响应式、暗色模式
- 构建产物是纯静态 HTML，扔到 Nginx 就完事
- 带货卡片、捐赠二维码可以做成组件复用

## 三、技术架构

```
┌─────────────────────────────────────────┐
│  Nginx（80/443 统一入口）                │
├──────────┬──────────────┬───────────────┤
│ 2rtk.com │ map.2rtk.com │ caster.2rtk.com│
│ VitePress│ Cesium 页面   │ NTRIP Caster   │
│ (静态)   │ (静态)       │ (5757/2101)    │
└──────────┴──────┬───────┴───────────────┘
                  │ 读取
        ┌─────────▼─────────┐
        │ data/*.json       │ ← 每 6h 由 lary.py 生成
        │ meta.json(时间)   │
        └───────────────────┘
```

> 和 Halo 版相比，**省掉了 Docker + Halo 容器 + 数据库**，三个站点全是静态 + 一个 caster 进程，架构更简单。
