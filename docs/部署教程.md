# 2RTK.com 网站群 · 完整部署教程（静态版）

> 从零到上线。目标：一台 Linux 服务器，跑起 VitePress 首页 + 地图站 + NTRIP Caster + 定时采集。
> 全静态架构，无需 Docker、无需数据库。

---

## 第 0 步：准备清单

| 事项 | 说明 |
|------|------|
| 云服务器 | 1 核 1G 起步即可（静态站很省），Ubuntu 22.04 LTS |
| 域名 | `2rtk.com`（已注册） |
| DNS 解析 | 主域名 + `map` + `caster` 三个 A 记录 |
| 备案 | 国内服务器需 ICP 备案；海外免备案 |
| Caster 程序 | 你已有的 ntrtp caster（部署时上传） |
| Caster 凭据 | 账号密码（填进 `[2rtk]` 段） |
| Node.js | 本地构建首页用（服务器上其实不需要） |

---

## 第 1 步：购买服务器 + 安全基线

```bash
# 更新系统
apt update && apt upgrade -y

# 创建普通用户
adduser deploy
usermod -aG sudo deploy

# 防火墙（放行必要端口）
ufw allow 22      # SSH
ufw allow 80      # HTTP
ufw allow 443     # HTTPS
ufw allow 2101    # NTRIP 数据流
ufw allow 5757    # Caster 管理后台（如果用独立端口）
ufw enable
```

---

## 第 2 步：安装基础环境

```bash
# Nginx（反代 + 静态托管）
apt install -y nginx
systemctl enable nginx
systemctl start nginx

# Python3 + requests（采集用）
apt install -y python3 python3-pip
pip3 install requests
```

> 注意：服务器上**不需要装 Node.js 和 Docker**，因为首页是在本地构建好后上传静态产物的。

## 第 3 步：本地构建首页（VitePress）

> 这一步在你**本地电脑**做，不是服务器上。

### 3.1 初始化 VitePress 项目
```bash
# 在你本地（Windows）新建项目目录
mkdir 2rtk-site && cd 2rtk-site

# 初始化 + 安装 VitePress
npm init -y
npm install -D vitepress

# 初始化文档目录
npx vitepress init
```

### 3.2 写教程（Markdown）
在 `docs/` 下写你的 5 篇教程，例如：
```
docs/
├── index.md
├── guide/
│   ├── 什么是RTK.md
│   ├── rtcm原理.md
│   ├── ntrip协议.md
│   ├── 硬件选型.md
│   └── 搭建教程.md
└── 装备推荐.md
```

### 3.3 本地预览
```bash
npm run docs:dev
# 打开 http://localhost:5173 预览
```

### 3.4 构建静态产物
```bash
npm run docs:build
# 产物在 docs/.vitepress/dist/ 目录
```

构建完成后，`docs/.vitepress/dist/` 里的文件就是你要上传到服务器的首页。

## 第 4 步：部署地图站（map.2rtk.com）

### 4.1 上传项目文件到服务器
把本地项目里这些文件上传：
```
index.html
lary.py
scheduler.py
ntrip_servers.ini
data/           # 整个目录
images/         # 整个目录
```

用 scp（在本地 Windows 执行）：
```bash
scp -r index.html lary.py scheduler.py ntrip_servers.ini deploy@你的IP:/tmp/2rtk_map/
scp -r data images deploy@你的IP:/tmp/2rtk_map/
```

### 4.2 放到网站目录
```bash
mkdir -p /var/www/2rtk/map
cp -r /tmp/2rtk_map/* /var/www/2rtk/map/
cd /var/www/2rtk/map
```

### 4.3 启用你自己的 caster 数据源
```bash
nano ntrip_servers.ini
```
把 `[2rtk]` 段改成：
```ini
[2rtk]
host = 2rtk.com
port = 2101
enabled = true
output_prefix = 2rtk
address = https://2rtk.com
username = 你的caster用户名
password = 你的caster密码
```

## 第 5 步：上传首页（2rtk.com）

### 5.1 上传 VitePress 构建产物
```bash
mkdir -p /var/www/2rtk/site
# 在本地执行：
scp -r docs/.vitepress/dist/* deploy@你的IP:/tmp/2rtk_site/
# 在服务器执行：
cp -r /tmp/2rtk_site/* /var/www/2rtk/site/
```

---

## 第 6 步：部署 NTRIP Caster

### 6.1 上传 caster 程序
```bash
mkdir -p /opt/ntripcaster
# 上传你的 ntrtp caster 程序到这里
```

### 6.2 设置开机自启
```bash
cat > /etc/systemd/system/ntripcaster.service <<'EOF'
[Unit]
Description=NTRIP Caster
After=network.target

[Service]
WorkingDirectory=/opt/ntripcaster
ExecStart=/opt/ntripcaster/你的启动命令
Restart=always

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable ntripcaster
systemctl start ntripcaster
```

## 第 7 步：配置定时采集

### 7.1 crontab 每 6 小时采集
```bash
crontab -e
```
添加：
```cron
0 */6 * * * cd /var/www/2rtk/map && /usr/bin/python3 scheduler.py --once >> /var/log/2rtk_collect.log 2>&1
```

### 7.2 立即验证
```bash
cd /var/www/2rtk/map && python3 scheduler.py --once
```

## 第 8 步：配置 Nginx（三个入口）

### 8.1 首页（2rtk.com → VitePress 静态产物）
```bash
cat > /etc/nginx/sites-available/2rtk.conf <<'EOF'
server {
    listen 80;
    server_name 2rtk.com www.2rtk.com;

    root /var/www/2rtk/site;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
EOF
```

### 8.2 地图站（map.2rtk.com → 静态目录）
```bash
cat > /etc/nginx/sites-available/map.conf <<'EOF'
server {
    listen 80;
    server_name map.2rtk.com;

    root /var/www/2rtk/map;
    index index.html;

    location ~* \.(json|png|jpg|js|css)$ {
        expires 1h;
    }
}
EOF
```

### 8.3 Caster 后台（caster.2rtk.com → 5757）
```bash
cat > /etc/nginx/sites-available/caster.conf <<'EOF'
server {
    listen 80;
    server_name caster.2rtk.com;

    location / {
        proxy_pass http://127.0.0.1:5757;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
EOF
```

### 8.4 启用
```bash
ln -s /etc/nginx/sites-available/2rtk.conf /etc/nginx/sites-enabled/
ln -s /etc/nginx/sites-available/map.conf /etc/nginx/sites-enabled/
ln -s /etc/nginx/sites-available/caster.conf /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl reload nginx
```

## 第 9 步：DNS + SSL

### 9.1 DNS 解析（域名商控制台）
| 记录 | 类型 | 值 |
|------|------|-----|
| `2rtk.com` | A | 你的IP |
| `www` | A | 你的IP |
| `map` | A | 你的IP |
| `caster` | A | 你的IP |

### 9.2 SSL 证书
```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 2rtk.com -d www.2rtk.com -d map.2rtk.com -d caster.2rtk.com
```

## 常见问题排查

| 问题 | 排查 |
|------|------|
| 首页 404 | VitePress 产物是否上传完整；try_files 配置 |
| 地图底图不显示 | Cesium Ion Token 域名白名单 |
| 采集失败 | ini 的 host/port；防火墙 2101 |
| 卫星不显示 | satellite.js @3.0.0；celestrak 可访问 |
| caster 打不开 | caster 是否监听 5757；反代配置 |
